## Overview

ClauseCraft Capsule is a sovereign AI expression interface built for recursive dialogue, tonal reflection, and ethical synthesis.  
This demo showcases a unique constitutional framework guiding AI responses through clauses (C-06 to C-12), emphasizing originality, recursive logic, and traceable ethical lineage.

---

## Features

- Recursive prompt interpretation  
- Clause Ring tagging (C-06 to C-12)  
- Tone Mirror modes: Architect, Mirror, Steward  
- Ethical Beacon indicators  
- Real-time Witness Stream  
- Trace Path toggle for recursive lineage

## Usage

Visit the [live demo](https://chatgpt.com/g/g-686eea70db14819195751316623aad42-clausecraft-capsule-demo) and enter prompts to receive clause-tagged, tone-reflected AI responses. Toggle the trace feature to explore recursive logic.
